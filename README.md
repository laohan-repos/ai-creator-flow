# CreatorFlow

把一本书编排为竖版书籍解说视频素材的本地 Web 工具。通过四步工作流，完成书籍脚本、分镜图片、旁白配音和剪映草稿的生成与管理。

仓库根目录是当前实现，`docs/` 保存八个模块的需求文档与设计稿。本文按当前代码说明功能和接入边界。

## 四步工作流

```text
准备模型配置与片头素材
          ↓
生成脚本 → 生成图片 → 生成配音 → 生成剪映草稿
          七段分镜：s0–s6
```

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 01 生成脚本 | 输入书名或让模型选书，选择片头，调整脚本提示词 | 保存书籍信息、七段口播、时长、语速与画面提示词 |
| 02 生成图片 | 为 s2–s6 生成配图，修改提示词或编辑已有图片 | 预览图片并切换历史图片版本 |
| 03 生成配音 | 按分镜生成旁白，调整口播和语速，试听音频 | 七段独立旁白；片头旁白按分配时长调整 |
| 04 生成剪映草稿 | 选择背景音乐，调整草稿提示词，调用草稿服务 | 保存草稿链接，查看、切换和移除草稿版本 |

当前分镜结构固定为：

- **s0**：开场钩子，使用片头视频。
- **s1**：固定口播「今天我们分享的是」，使用片头视频。
- **s2**：书名揭示，固定口播「《当前书名》。」，使用独立配图。
- **s3–s6**：展开作者、背景、情节、观点和情绪升华，使用独立配图。

脚本以约 26 秒为目标编排；最终时间轴还取决于片头长度和真实配音时长，不保证固定为 26 秒。

## 已有功能

- **书籍项目管理**：保存和打开项目，编辑书名、作者等信息，删除项目。
- **独立模型配置**：分别配置文生图、图生图、多模态（脚本）、视频和语音能力，支持连接测试。
- **素材库**：上传片头、片尾和背景音乐，管理默认片头；支持通过 Seedance 接口生成视频素材并查询任务状态。
- **图片版本管理**：重新生成或编辑分镜图片，保留并切换图片版本。
- **草稿编排**：组合片头、图片、旁白、字幕、标题和作者信息，为图片添加运动关键帧；背景音乐以 12% 音量循环铺满时间轴。
- **草稿版本管理**：保存每次生成的版本，复制链接或设置当前版本；移除记录不会删除外部服务中的草稿。
- **批量生成**：一次处理 1–20 本书，逐本执行脚本、图片、配音和草稿生成，显示步骤与进度。选书提示词会排除已加载的书目和本批次书目，仍需人工检查重复。
- **本地持久化**：使用 SQLite 保存项目、分镜、模型配置、素材和草稿记录。

## 环境准备

| 依赖 | 说明 |
| --- | --- |
| Node.js | 建议使用 22.13 或更高版本，需能直接导入 `node:sqlite` |
| npm | 安装依赖、启动和构建项目 |
| FFmpeg / ffprobe | 服务端通过 `ffprobe` 读取真实媒体时长，需加入系统 `PATH` |
| 浏览器 | 用于操作本地页面、预览图片与音频 |
| 外部服务 | 脚本、图片、语音及草稿生成需要相应服务；视频生成和图片编辑按需配置 |

检查本地环境：

```bash
node --version
npm --version
node -e "require('node:sqlite'); console.log('SQLite 可用')"
ffprobe -version
```

## 快速开始

在项目根目录执行：

```bash
npm install
cp .env.example .env.local
npm run dev
```

如果已有 `.env.local`，保留原文件。Windows PowerShell 可用 `Copy-Item .env.example .env.local` 完成首次复制。

打开 [本地应用](http://localhost:3000)，按以下顺序完成首次使用：

1. 在模型配置中保存脚本、文生图和语音服务配置，并测试连接。
2. 打开素材库，上传可用片头并设置默认片头；可按需上传背景音乐。片头至少需要 **2.3 秒**，还须能够容纳前两段实际旁白。
3. 回到创作页面，选择片头，输入书名或留空让模型选书，生成并审阅脚本。
4. 为 s2–s6 生成图片，为 s0–s6 生成配音，逐段检查内容与时长。
5. 满足下文的草稿服务接入条件后，生成剪映草稿并检查结果。

生产模式运行：

```bash
npm run build
npm run start
```

## 模型与服务配置

五类模型能力可以分别设置 Base URL、模型名称和 API Key，语音还可设置发音人。页面保存的能力配置覆盖对应环境配置；服务端读取 Key 时优先使用该能力已保存的 Key，没有时回退到 `AI_API_KEY`。保存时留空 Key 会保留原值，页面不会回显已保存的 Key。

| 能力 | 当前代码使用的接口 | 环境变量 |
| --- | --- | --- |
| 多模态 / 脚本 | Chat Completions `/chat/completions`，返回可解析的 JSON 文本 | `AI_TEXT_MODEL` |
| 文生图 | OpenAI Images `/images/generations`，或 MiniMax `/image_generation` | `AI_IMAGE_MODEL` |
| 图生图 | Images Edits `/images/edits`，multipart 上传图片 | `AI_IMAGE_EDIT_MODEL` |
| 视频 | Seedance `/contents/generations/tasks`，创建并查询任务 | `AI_VIDEO_MODEL` |
| 语音 | MiniMax `/t2a_v2`，返回十六进制 MP3 音频 | `AI_VOICE_MODEL`、`AI_VOICE_ID` |

`AI_BASE_URL` 和 `AI_API_KEY` 提供共享回退值，其余变量见 [.env.example](.env.example)。示例文件中的模型名和地址仅用于配置参考，需要替换成实际服务支持的组合。五类能力并非统一协议，单一 OpenAI 兼容地址或 Key 不一定能支持全部功能。

连接测试不等同于完整生成验收：非语音能力主要检查模型列表或接口可访问性；语音测试会实际调用短句合成。

## 剪映草稿接入边界

当前代码通过 **CapCut Mate** 接口创建草稿、添加媒体并保存草稿链接。服务地址固定在 `lib/jianying.ts`，不使用上述模型 Base URL。这是外部草稿服务集成，仓库没有实现本地 MP4 渲染，也没有直接写入剪映桌面端原生草稿目录。

**默认素材地址存在网络可达性限制。** `app/api/projects/draft/route.ts` 会构造 `http://127.0.0.1:<端口>/api/...` 素材地址并传给草稿服务。远程服务通常无法读取你电脑上的回环地址；仅启动本地应用不足以保证草稿生成成功。实际使用前，需要适配素材发布和访问地址，或部署能够访问素材的草稿服务。当前没有通过环境变量配置素材公共地址的入口。

草稿生成还要求：已选择可用片头、s2–s6 均有配图、全部七段均有配音，且前两段旁白不超过片头分配时长。素材库虽可管理片尾，当前草稿编排没有加入片尾轨道。草稿能否在目标剪映版本中正常打开，需要使用真实服务和客户端验证。

## 本地数据与运行限制

- 数据库在首次访问相关功能时自动创建于 `data/creatorflow.db`，无需单独部署数据库服务。
- 素材二进制内容及项目记录保存在 SQLite 中，生成图片可能保存为外部 URL 或 Base64；远程 URL 的长期可用性取决于提供方。
- API Key 保存在本地环境文件或数据库中，当前没有额外的静态加密；备份数据库时也会包含已保存的 Key。
- `.env.local` 和 `data/` 已被 Git 忽略。迁移或清理数据前，停止应用并备份数据库，避免在教学录屏中展示真实 Key。
- 当前面向本地使用，没有用户登录和多租户权限隔离。
- 批量任务由浏览器页面串行调度，执行期间应保持页面打开；失败会中断本批次，尚无持久化后台队列或刷新后自动续跑机制。
- 未配置服务或外部调用失败时会显示错误，不以占位图片、模拟音频或假草稿链接替代结果。生成内容仍需人工核对书籍事实、画面与口播。

## 技术栈与目录

使用 Next.js 15.2.4 App Router、React 19、TypeScript 5.8 和 Node.js 内置 SQLite。服务端通过原生 `fetch` 调用外部接口，样式由项目 CSS 实现，没有引入 UI 框架或 ORM。

```text
app/
  page.tsx                 主工作台：项目、模型配置、四步创作、批量任务
  create/page.tsx          复用主工作台的创作入口
  assets/page.tsx          素材库
  api/                    模型配置、生成、项目、素材和草稿接口
  styles.css              页面样式
lib/
  types.ts                项目、分镜与素材类型
  model-config.ts         模型配置与 Key 的本地存储
  projects.ts             项目、分镜和草稿版本存储
  intros.ts               素材库与视频任务存储
  script-prompt.ts         默认脚本提示词
  draft-prompt.ts          默认草稿提示词
  jianying.ts              草稿服务调用与时间轴编排
  media-duration.ts        ffprobe 媒体时长探测
  api-url.ts               外部接口地址处理
  http-media.ts            媒体响应与 Range 请求支持
docs/                     八个模块的需求文档与设计稿
starter-template/         学员起始项目
scripts/validate-course.mjs 文档检查脚本
data/                     运行时数据库，不提交到 Git
```

## 常见问题

| 问题 | 排查方向 |
| --- | --- |
| 无法导入 `node:sqlite` | 检查启动项目的 Node.js 版本，并运行上面的 SQLite 检查命令 |
| 提示未安装 ffprobe | 安装 FFmpeg，确认启动应用的终端能够执行 `ffprobe -version` |
| 页面能打开，生成失败 | 检查对应能力的 Base URL、模型、Key 和接口协议；按能力分别验证 |
| 提示片头不足或旁白超时 | 换用更长片头、缩短 s0 口播或重新生成配音 |
| 本地素材能播放，草稿生成失败 | 检查外部服务能否访问素材地址，参见「剪映草稿接入边界」 |
| 批量生成中断 | 查看当前步骤错误；已保存项目可重新打开，修复配置或素材后继续单本处理 |
