# 阶段 06：分镜配音

## 目标

为七个分镜生成真实 MP3 旁白，并使用真实音频时长处理 s0、s1 的片头预算。

## 开始前

阅读：

- `AGENTS.md`
- `docs/CreatorFlow-需求文档.md` 第 7.4 节
- `docs/course/api-contracts.md` 第 5 节

## 需求

1. 配音步骤展示 s0–s6 七个分镜。
2. 用户可以修改口播、计划时长和语速。
3. 语速限制为 0.5–2.0。
4. 调用语音能力配置和 MiniMax `t2a_v2` 格式。
5. 请求输出 MP3、32000 Hz、128 kbps、单声道。
6. 把接口返回的十六进制音频转换为字节并读取真实时长。
7. s0、s1 请求携带目标时长；其他分镜不携带。
8. 首次音频超过目标时长时，按比例提高语速并重试一次，最高 2.0。
9. 第二次仍超过目标 0.08 秒以上时返回明确错误。
10. 成功后返回音频 Data URI、真实时长和最终语速。
11. 页面展示播放器，生成成功后立即持久化音频和最终语速。

## 不做

- 不使用浏览器朗读 API 代替服务端合成。
- 不用计划时长假装真实音频时长。
- 不在本阶段生成剪映草稿。

## 验收

- 七段均可独立生成和重新生成。
- 页面可试听成功音频。
- s0、s1 具有一次自动语速适配。
- 无法塞入片头时提示缩短口播或更换片头。
- 刷新后音频仍存在。
- `npm run build` 通过。

## 发给 Codex

重点使用真实媒体时长实现 s0、s1 的一次语速重试，不要用估算时长替代。
