# 阶段 08：剪映草稿与批量生成

## 目标

把片头、五张图片、七条旁白、字幕、标题、作者和背景音乐组合为剪映草稿，并实现 1–20 本串行批量生成。

## 开始前

阅读：

- `AGENTS.md`
- `docs/CreatorFlow-需求文档.md` 第 7.6、7.7、8 节
- `docs/course/api-contracts.md` 第 9、10 节
- `docs/course/acceptance-checklist.md` 第 9、10 节

## A. 剪映草稿需求

1. 生成前校验项目、片头、s2–s6 五张图片和七条旁白完整。
2. 默认创建 1080×1920 草稿。
3. 片头从 0 开始，保留 60% 原声；s0、s1 使用片头画面。
4. s2 从片头结束开始，s2–s6 图片时长等于对应旁白真实时长。
5. 图片按比例铺满画布，并随机使用推进、拉远、平移、对角移动或轻微旋转关键帧。
6. 书名和作者从 s2 第一帧显示到结束。
7. 作者过长时自动缩小字号并合理换行。
8. 字幕按中英文标点拆分，并按文本长度比例分配在分镜时间内。
9. 七条旁白音量为 100%。
10. 可选背景音乐以 12% 音量循环铺满，最后一段按剩余时长截断。
11. 默认草稿提示词允许用户修改；解析分辨率、标题、作者和字幕样式，无法解析时使用默认值。
12. 每次成功生成保存一个草稿版本及当次提示词。
13. 支持复制链接、切换当前版本和移除版本记录。
14. 移除版本记录不得宣称删除外部草稿。

## B. 批量生成需求

1. 数量限制为 1–20。
2. 同一批次统一使用所选片头和可选背景音乐。
3. 片头必须存在且不少于 2.3 秒。
4. 把已有书目和本批次成功书目加入强制去重黑名单。
5. 每本串行执行：去重 → 脚本 → 五张图片 → 七条配音 → 草稿 → 完成。
6. 页面展示总进度、当前书籍、当前步骤、步骤详情和任务队列。
7. 执行时禁止关闭批量窗口。
8. 任一步骤失败时标记当前任务失败、显示原因并停止后续书籍。
9. 保留失败前已经生成和保存的项目及素材。
10. 当前阶段不实现自动重试或断点续跑。

## 集成要求

- 草稿生成前先保存页面中的最新分镜和背景音乐选择。
- 外部草稿服务错误需指出具体失败操作。
- 项目步骤状态由真实素材完整度决定。
- 不以“已发送请求”代替“草稿已保存”。

## 验收

- 完成最终验收清单第 9 节全部项目。
- 按第 10 节完成一次端到端演示。
- 至少生成两个草稿版本并成功切换。
- 至少执行一次两本书的批量任务。
- `npm run build` 和 `npm run course:check` 均通过。
