# 阶段 05：分镜图片

## 目标

为 s2–s6 生成五张真实图片，支持提示词编辑、重新生成、版本切换、大图查看和图生图编辑。

## 开始前

阅读：

- `AGENTS.md`
- `docs/CreatorFlow-需求文档.md` 第 7.3 节
- `docs/course/api-contracts.md` 第 3、4 节

## 需求

1. 图片步骤只展示 s2–s6。
2. 用户可以编辑每个分镜的图片提示词。
3. 文生图支持 MiniMax 和 OpenAI Images 兼容协议。
4. MiniMax 使用 9:16；OpenAI 兼容接口使用 1024×1536。
5. 每次请求追加禁止文字、Logo 和水印的要求。
6. 如果请求因未成年人安全限制失败，自动将相关人物改为成年人、剪影、空镜或象征物后重试一次。
7. 每个分镜保存当前图片和去重后的版本列表。
8. 重新生成不删除历史版本。
9. 用户可以查看大图并选择任一版本作为当前图片。
10. 图生图将当前图片和编辑提示词以 multipart 提交，结果加入版本列表并设为当前。
11. 生成、编辑和切换版本后立即持久化。

## 状态要求

- 每个分镜独立显示等待、生成中、成功或失败状态。
- 执行中的按钮不可重复点击。
- 安全改写成功时明确告知用户。
- 没有原图时不得提交图生图。

## 不做

- 不为 s0、s1 生成图片。
- 不伪造占位图作为成功结果。
- 不在本阶段生成配音或草稿。

## 验收

- 五个分镜均可生成真实图片。
- 重新生成后版本数量增加。
- 切换历史版本后刷新仍保持选中结果。
- 图生图结果成为新版本。
- 安全重试最多一次。
- `npm run build` 通过。

## 发给 Codex

```text
请阅读 AGENTS.md、阶段 05、产品需求 7.3 和图片 API 契约。
只实现 s2–s6 图片生成、版本和图生图，使用真实接口，不创建占位图片。
完成后运行 npm run build，并报告持久化、安全重试和版本切换验收。
```
