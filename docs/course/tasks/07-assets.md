# 阶段 07：片头与背景音乐

## 目标

完成素材库：上传、试听、默认片头、删除关联处理，以及 Seedance 片头异步任务。

## 开始前

阅读：

- `AGENTS.md`
- `docs/CreatorFlow-需求文档.md` 第 7.5 节
- `docs/course/api-contracts.md` 第 6、10 节
- `docs/course/examples/assets/README.md`

## 需求

1. 素材类型至少包括 `intro` 和 `bgm`。
2. 上传片头只接受视频，限制 100 MB。
3. 上传背景音乐只接受音频，限制 30 MB。
4. 名称为空时使用去掉扩展名的文件名。
5. 服务端读取并保存媒体真实时长和二进制内容。
6. 第一个片头自动设为默认；用户可切换默认片头。
7. 页面支持视频和音频试听。
8. Seedance 片头输入名称、提示词和 2–12 秒时长。
9. 创建任务固定使用 9:16、720p、无水印、无音频。
10. 保存任务 ID 和 queued/running/ready/failed 状态。
11. 用户主动刷新任务；成功后下载视频、读取真实时长并保存。
12. 删除素材前二次确认；删除后解除项目的片头或背景音乐关联。
13. 删除默认片头后，从剩余片头中选一个作为默认。

## 媒体响应

- 素材 GET 接口应返回正确 Content-Type。
- 支持浏览器音视频播放器所需的 Range 请求。
- Seedance 任务未完成时不得返回空视频，使用 409 状态。

## 不做

- 当前页面不实现片尾管理。
- 不自动轮询 Seedance；由用户刷新。
- 不绕过文件大小和 MIME 类型校验。

## 验收

- 能上传、保存、刷新后试听片头和音乐。
- 第一个片头自动成为默认。
- Seedance 状态可以从等待更新到成功或失败。
- 删除素材后项目引用被解除。
- 过大或类型错误文件被拒绝。
- `npm run build` 通过。
