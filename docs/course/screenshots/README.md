# 界面取图清单

当前完整参考实现就是界面标准。课程发布前，教学者应使用统一浏览器尺寸截取以下状态，并将图片放入本目录。

建议桌面尺寸：1440×1000；建议窄屏尺寸：390×844。

| 文件名 | 页面或状态 | 必须展示 |
| --- | --- | --- |
| `01-project-list.png` | 项目列表 | 导航、项目行、新建与批量按钮 |
| `02-empty-list.png` | 空项目列表 | 空状态和新建引导 |
| `03-script-step.png` | 脚本步骤 | 书名、片头、音乐和提示词入口 |
| `04-script-result.png` | 七段脚本 | s0–s6、总时长和图片提示词入口 |
| `05-image-step.png` | 图片步骤 | 五个分镜、生成状态和操作按钮 |
| `06-image-versions.png` | 图片编辑 | 当前图片、版本列表和编辑提示词 |
| `07-voice-step.png` | 配音步骤 | 七段旁白、播放器和修改入口 |
| `08-draft-step.png` | 草稿步骤 | 音乐、生成按钮和版本列表 |
| `09-assets.png` | 素材库 | 上传、Seedance、素材预览和默认状态 |
| `10-model-config.png` | 模型弹窗 | 五项标签、Key 状态和测试按钮 |
| `11-batch-setup.png` | 批量设置 | 数量、片头、音乐和预览 |
| `12-batch-progress.png` | 批量进度 | 总进度、执行步骤和任务队列 |
| `13-mobile.png` | 窄屏 | 导航和关键内容可访问 |

取图规则：

- 隐藏或打码真实 API Key、服务地址和私人素材文件名。
- 使用固定示例项目，避免截图之间数据不一致。
- 加载态、失败态和空状态至少各保留一张。
- 截图只作为视觉参考，任务验收仍以功能和数据规则为准。
