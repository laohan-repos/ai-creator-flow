# 示例素材准备

课程仓库不附带第三方视频或音乐，避免版权和体积问题。教学者应自行准备可授权用于教学的素材。

## 片头

- 文件名建议：`intro-demo.mp4`
- 类型：MP4 或 MOV
- 比例：9:16
- 时长：建议 4 秒，必须不少于 2.3 秒
- 分辨率：建议 720×1280 或 1080×1920
- 大小：不超过 100 MB
- 内容：抽象书页、光影或无具体版权角色的氛围镜头

额外准备一个 2 秒片头，用于演示“片头过短”错误。

## 背景音乐

- 文件名建议：`bgm-demo.mp3`
- 类型：MP3、M4A 或 WAV
- 时长：建议 30–60 秒
- 大小：不超过 30 MB
- 内容：无歌词、音量平稳、明确允许教学使用

## 验收素材

建议同时准备：

- 一个错误类型文件，用于验证 MIME 校验。
- 一个超过限制的临时文件，只在本地验证大小限制，不要提交仓库。
- 一个 3–6 秒成功片头和一段成功音乐，用于最终演示。

## 安全提醒

- 不要把付费素材原文件打包发给无授权学员。
- 不要使用包含个人隐私、真实证件或未授权人像的素材。
- 录屏时检查文件名和播放器画面是否适合公开。
