# 验收清单

## 1. 通用质量

- [ ] `npm install` 成功。
- [ ] `npm run build` 成功。
- [ ] `npm run course:check` 成功。
- [ ] TypeScript 没有通过新增 `any` 规避错误。
- [ ] 页面和接口错误使用可理解的中文说明。
- [ ] `.env.local`、数据库和真实 API Key 未提交。
- [ ] 已保存 API Key 不在页面或接口响应中回显。

## 2. 阶段一：项目骨架

- [ ] `/`、`/create`、`/assets` 可以访问。
- [ ] 三个页面具有一致的左侧导航和品牌区域。
- [ ] 项目列表有标题、数量、空状态、新建和批量入口。
- [ ] 制作页展示四步导航。
- [ ] 素材页展示片头和背景音乐分类。
- [ ] 页面使用 Design Spec 中的紫色主色、浅灰画布、白色面板和统一状态色。
- [ ] 主按钮、次按钮、危险按钮、输入框和弹窗符合组件规范。
- [ ] 侧栏在 621–900 px 收窄，在 620 px 以下转换为顶部布局。
- [ ] 窄屏下没有关键内容完全不可访问。

## 3. 阶段二：项目存储

- [ ] 首次访问自动创建 SQLite 数据库和数据表。
- [ ] 可以创建并读取一个包含七段分镜的项目。
- [ ] 项目列表按新到旧展示，最多 50 条。
- [ ] 可以编辑书名、作者和核心情绪。
- [ ] 空书名不能保存。
- [ ] 删除前二次确认，删除后关联分镜不存在。
- [ ] 页面刷新后项目仍存在。

## 4. 阶段三：模型配置

- [ ] 五类能力独立配置。
- [ ] 语音能力可以保存发音人 ID。
- [ ] 不填写新 Key 时不会清空旧 Key。
- [ ] GET 响应只有 `apiKeyConfigured`，没有 Key。
- [ ] 页面可以测试连接并显示成功、失败或超时状态。
- [ ] 环境变量可以作为未保存配置的回退值。

## 5. 阶段四：脚本

- [ ] 未选择片头时禁止生成。
- [ ] 片头不足 2.3 秒时禁止生成。
- [ ] 指定书名和自动选书两种方式均可提交。
- [ ] 自动选书提示词包含已有书目黑名单。
- [ ] 模型输出不是正好七段时返回错误。
- [ ] 每段口播非空，s2–s6 图片提示词非空。
- [ ] s1 被强制修正为“今天我们分享的是”。
- [ ] s2 被强制修正为“《当前书名》。”。
- [ ] s0、s1 时长总和等于片头时长。
- [ ] 生成成功后项目保存并可重新打开。

## 6. 阶段五：图片

- [ ] 只展示 s2–s6 五个图片生成项。
- [ ] 可编辑提示词并生成图片。
- [ ] 图片请求明确禁止文字、Logo 和水印。
- [ ] 安全限制触发后只自动改写重试一次。
- [ ] 重新生成会保留历史版本。
- [ ] 可以切换任一历史版本为当前图片。
- [ ] 可以查看当前图片大图。
- [ ] 可以基于当前图片执行图生图编辑。
- [ ] 刷新页面后当前图片和版本仍存在。

## 7. 阶段六：配音

- [ ] 七个分镜都可以独立生成配音。
- [ ] 可以修改口播、时长和语速。
- [ ] 语速限制为 0.5–2.0。
- [ ] s0、s1 超时后会自动提高语速并重试一次。
- [ ] 重试后仍超出预算时返回明确错误。
- [ ] 成功后展示音频播放器和真实时长。
- [ ] 刷新页面后音频仍可播放。

## 8. 阶段七：素材

- [ ] 可上传不超过 100 MB 的视频片头。
- [ ] 可上传不超过 30 MB 的背景音乐。
- [ ] 非法媒体类型被拒绝。
- [ ] 系统读取真实媒体时长。
- [ ] 第一个片头自动成为默认片头。
- [ ] 可以切换默认片头。
- [ ] 可以创建并刷新 Seedance 片头任务。
- [ ] 可以试听成功素材。
- [ ] 删除素材后项目引用被解除。

## 9. 阶段八：草稿与批量

- [ ] 图片或配音不完整时禁止生成草稿。
- [ ] 草稿画布默认为 1080×1920。
- [ ] s0、s1 使用片头；s2–s6 使用五张图片。
- [ ] 图片时长和旁白时间线使用真实音频时长。
- [ ] 标题和作者从 s2 显示到结尾。
- [ ] 字幕按标点拆分并按文本长度分配时长。
- [ ] 背景音乐以 12% 音量循环铺满。
- [ ] 每次生成保存新草稿版本。
- [ ] 可以复制、切换和移除草稿版本。
- [ ] 批量数量限制为 1–20。
- [ ] 批量生成避开已有和本批次已生成书目。
- [ ] 页面显示当前任务、步骤和总进度。
- [ ] 任一步骤失败后当前批次中断并展示原因。

## 10. 最终演示脚本

1. 上传并设定一个 3–6 秒片头。
2. 上传一段背景音乐。
3. 配置五项模型能力并展示 Key 不回显。
4. 输入“活下去的理由”生成七段脚本。
5. 修改一个图片提示词并生成五张图片。
6. 对一张图片执行重新生成、版本切换和图生图。
7. 生成七条配音，并播放其中一条。
8. 生成剪映草稿并复制链接。
9. 修改草稿提示词后再次生成，展示两个版本。
10. 返回项目列表，刷新页面并重新打开项目。
11. 启动两本批量任务，展示逐本进度和去重结果。
