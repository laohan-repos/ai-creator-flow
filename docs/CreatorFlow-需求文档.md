## 2. 产品概述

CreatorFlow 是一个面向书籍短视频生产场景的 AI 辅助工具。用户输入一本书名，或由模型自动选择一本书，系统依次生成书籍解说脚本、分镜图片、分镜配音，并将片头、图片、旁白、字幕、书名、作者和背景音乐整理为可继续编辑的剪映草稿。

产品同时支持单本书籍的逐步制作和多本书籍的批量自动生产。

## 3. 产品目标

### 3.1 核心目标

- 将书籍短视频制作流程统一为四个连续步骤。
- 降低书籍内容整理、脚本编写、配图、配音和剪映草稿组装的操作成本。
- 保留脚本、图片提示词、图片版本、旁白参数和剪映草稿版本的可编辑性。
- 支持一次自动生成多本不重复的书籍解说。

### 3.2 当前交付结果

每个完整项目最终包含：

- 一本书的基础信息和解说摘要。
- s0–s6 共 7 个分镜。
- s2–s6 共 5 张分镜图片。
- s0–s6 共 7 条旁白音频。
- 一个片头视频。
- 可选的背景音乐。
- 一个或多个剪映草稿版本及草稿链接。

## 4. 目标用户与使用场景

### 4.1 目标用户

需要制作竖版书籍解说短视频的个人内容创作者或内容运营人员。

### 4.2 核心场景

#### 场景一：制作指定书籍解说

用户输入书名，选择片头和背景音乐，生成书籍脚本，并逐步完成图片、配音和剪映草稿。

#### 场景二：由模型自动选书

用户不填写书名，由模型选择适合解读的书籍。系统自动排除项目库中已经生成的书目。

#### 场景三：批量生产书籍解说

用户设置 1–20 的生成数量，并选择统一的片头和背景音乐。系统逐本自动选书，并完成脚本、图片、配音和剪映草稿。

#### 场景四：修改已有项目

用户从项目列表打开已有书籍解说，对图片提示词、图片版本、旁白文案、语速、背景音乐和剪映草稿样式进行调整并重新生成。

## 5. 产品信息架构

产品左侧导航包含三个入口：

| 入口 | 页面 | 主要用途 |
| --- | --- | --- |
| 书籍解说 | `/` | 查看、编辑、删除项目及启动批量生成 |
| 素材库 | `/assets` | 管理片头视频和背景音乐 |
| 模型 | `/create?model=1` | 配置和测试各项 AI 模型能力 |

新建或打开项目后进入 `/create`，按照以下四步完成制作：

1. 生成书籍解说脚本。
2. 生成图片。
3. 生成配音。
4. 生成剪映草稿。

## 6. 核心业务流程

### 6.1 单本制作流程

1. 用户进入书籍解说列表并点击“新建书籍解说”。
2. 用户输入书名，或留空由模型自动选书。
3. 用户选择一个可用片头，可选背景音乐。
4. 系统调用多模态模型生成书籍信息及 s0–s6 七个分镜。
5. 系统保存项目并进入图片生成步骤。
6. 用户为 s2–s6 分别生成图片，可修改提示词、重新生成或图生图编辑。
7. 用户为 s0–s6 分别生成配音，可修改口播、时长和语速。
8. 用户确认背景音乐和剪映草稿提示词。
9. 系统校验图片、配音和片头是否完整。
10. 系统调用剪映草稿服务，按时间线写入视频、图片、动画、字幕和音频。
11. 系统保存草稿链接和草稿版本。

### 6.2 批量制作流程

1. 用户在书籍解说列表点击“批量生成”。
2. 用户填写生成数量，范围为 1–20。
3. 用户选择本批次统一使用的片头和可选背景音乐。
4. 系统读取已有项目书名，生成不可选书目清单。
5. 系统依次执行每本书的任务，不并行处理同一批次中的书籍。
6. 每本任务依次经历：准备去重清单、生成脚本、生成 5 张图片、生成 7 条配音、生成剪映草稿、完成。
7. 当前书籍完成后，系统将其书名加入本批次去重清单，再处理下一本。
8. 任一环节失败时，当前任务标记失败，批量流程中断并显示错误原因。

## 7. 功能需求

## 7.1 书籍解说项目管理

### 7.1.1 项目列表

- 系统按项目 ID 倒序展示最近 50 个项目。
- 每个项目展示书名、作者、核心情绪和创建日期。
- 作者为空时展示“作者待核实”。
- 核心情绪为空时展示“情绪待核实”。
- 点击项目主体或打开入口后，进入该项目的制作页面。
- 无项目时展示空状态和新建引导。

### 7.1.2 新建项目

- 用户点击“新建书籍解说”进入制作页面。
- 项目在脚本成功生成后创建并保存，不在进入页面时创建空项目。

### 7.1.3 编辑项目基础信息

- 用户可修改书籍解说名称、作者和核心情绪。
- 书籍解说名称为必填项。
- 保存后同步更新项目列表中的信息。

### 7.1.4 删除项目

- 删除前必须弹出二次确认。
- 删除项目时一并删除分镜、图片和音频记录、项目视频记录及草稿版本关联数据。
- 删除操作不可在产品内恢复。

## 7.2 脚本生成

### 7.2.1 输入项

| 输入项 | 必填 | 规则 |
| --- | --- | --- |
| 书名 | 否 | 留空时由模型自动选书 |
| 片头 | 是 | 真实时长不得小于 2.3 秒 |
| 背景音乐 | 否 | 可选择素材库中的背景音乐，也可不使用 |
| 脚本提示词 | 是 | 默认使用系统提示词，支持用户编辑和恢复默认 |

### 7.2.2 自动选书去重

- 未输入书名时，系统将已有项目书名加入提示词黑名单。
- 模型不得选择相同书名，也不得选择同一本书的简称、全称、别名、副标题版本或仅标点不同的写法。
- 最终书名应保存为不带书名号和副标题的标准主标题。

### 7.2.3 模型输出

模型必须返回严格 JSON，内容包含：

- 书名 `bookTitle`。
- 作者 `author`。
- 核心情绪 `mood`。
- 开场钩子 `hook`。
- 内容摘要 `summary`。
- 正好 7 条分镜 `scenes`。

每条分镜包含：

- 分镜标题。
- 口播文案。
- 语速。
- 计划时长。
- 图片提示词。

### 7.2.4 七段分镜规则

| 分镜 | 职责 | 画面 | 口播规则 |
| --- | --- | --- | --- |
| s0 | 开场钩子 | 使用片头视频 | 根据书籍主题生成简短钩子 |
| s1 | 引出书籍 | 使用片头视频 | 必须逐字为“今天我们分享的是” |
| s2 | 书名揭示 | 书籍专属主视觉图片 | 必须为“《当前书名》。” |
| s3 | 正文解读 | 独立配图 | 根据可靠内容生成正文 |
| s4 | 正文解读 | 独立配图 | 推进内容和情绪 |
| s5 | 正文解读 | 独立配图 | 推进内容和情绪 |
| s6 | 结尾收束 | 独立配图 | 完成情绪升华或总结 |

补充规则：

- s0 和 s1 的图片提示词必须为空。
- s2–s6 的图片提示词不能为空。
- s1 不得包含年代、地点、人物或故事情节。
- s2 图片必须表现当前书籍最具代表性的核心意象。
- 图片提示词不得要求画面出现文字、书名、Logo 或水印。
- 不确定的作者、年代和情节应使用“待核实”，不得编造。

### 7.2.5 时长规则

- 整条视频目标时长为 26 秒。
- 默认提示词要求总时长控制在 24–28 秒。
- s0、s1 的时长总和等于所选片头的真实时长。
- 系统根据两段口播长度，为 s0、s1 分配片头时间。
- s1 语速固定为 1.2，s0 语速固定为 1.0。
- s2 时长不得小于 0.8 秒。
- s3–s6 按模型给出的相对时长比例分配剩余时间。

### 7.2.6 脚本查看

- 脚本生成后展示书名、开场钩子、总计划时长和七个分镜。
- s2–s6 提供图片提示词查看和编辑入口。
- 用户可以返回脚本步骤查看内容。

## 7.3 分镜图片

### 7.3.1 图片生成范围

- 只为 s2–s6 生成图片，共 5 张。
- 每张图片按对应分镜的图片提示词单独生成。
- 用户可以在生成前修改图片提示词。
- 图片生成成功后立即保存至当前项目。

### 7.3.2 图片规格

- MiniMax 图片接口使用 9:16 画面比例。
- OpenAI 兼容图片接口使用 1024 × 1536 尺寸。
- 所有生成请求追加“不要出现文字、Logo 或水印”的限制。

### 7.3.3 安全改写

- 当图片请求因未成年人安全限制被拒绝时，系统自动改写提示词。
- 改写规则包括将未成年人替换为成年人物、远景剪影、空镜或象征性物件。
- 自动改写后只重试一次。
- 重试成功时提示用户图片经过安全改写。
- 重试仍失败时，提示用户手动修改图片提示词。

### 7.3.4 重新生成与版本

- 已生成图片可重新生成。
- 每次成功生成的图片加入该分镜的图片版本列表。
- 相同图片地址不得重复加入版本列表。
- 用户可以查看版本缩略图并将任一版本设为当前图片。
- 用户可以点击当前图片查看大图。

### 7.3.5 图生图编辑

- 有当前图片时，用户可输入编辑提示词并发起图生图。
- 系统将当前图片作为原图提交。
- 图生图输出尺寸为 1024 × 1536。
- 编辑结果加入图片版本列表并自动设为当前图片。

## 7.4 分镜配音

### 7.4.1 配音范围

- s0–s6 均需单独生成旁白，共 7 条。
- 每条旁白使用该分镜的口播内容和语速参数。
- 生成成功后展示音频播放器和真实音频时长。
- 音频生成成功后立即保存至项目。

### 7.4.2 编辑参数

- 用户可修改口播内容。
- 用户可修改计划时长，页面输入范围为 0.3–30 秒。
- 用户可修改语速，范围为 0.5–2.0。

### 7.4.3 片头内配音适配

- s0、s1 生成配音时必须携带目标时长。
- 如果首次合成音频超过目标时长，系统根据实际音频时长自动提高语速并重新合成一次。
- 自动调整后的语速不得超过 2.0。
- 重试后仍超出目标时长 0.08 秒以上时，生成失败，并提示缩短口播或更换更长片头。

### 7.4.4 音频规格

- 输出格式为 MP3。
- 采样率为 32000 Hz。
- 码率为 128000。
- 单声道输出。

## 7.5 素材库

### 7.5.1 素材分类

素材库需要提供以下三类素材：

- 片头视频。
- 片尾视频。
- 背景音乐。

当前页面只展示片头和背景音乐；片尾的服务端存储与接口已有支持，页面入口仍需实现。

### 7.5.2 上传片头

- 支持浏览器识别为视频的文件，例如 MP4、MOV。
- 单个片头文件不得超过 100 MB。
- 素材名称可选，未填写时使用文件名。
- 系统读取并保存视频真实时长。
- 第一个上传成功的片头自动设为默认片头。
- 用户可将其他可用片头设为默认。
- 同一时间只允许一个默认片头。

### 7.5.3 Seedance 生成片头

- 用户可填写素材名称、视频提示词和生成时长。
- 视频提示词为必填项。
- 生成时长限制为 2–12 秒。
- 输出比例固定为 9:16，分辨率为 720p，不加水印，不生成音频。
- 创建任务后状态为等待生成。
- 用户通过“刷新状态”主动查询任务状态。
- 任务状态包括等待生成、正在生成、生成成功和生成失败。
- 任务成功后系统下载视频、读取真实时长并保存到本地数据库。

### 7.5.4 上传片尾

- 支持上传视频文件，大小不超过 100 MB，并保存真实时长。
- 支持通过 Seedance 生成片尾并查看任务状态。
- 片尾在素材库中可预览、管理和删除，不设默认项。
- 当前剪映草稿编排尚未加入片尾轨道。

### 7.5.5 上传背景音乐

- 支持浏览器识别为音频的文件，例如 MP3、M4A、WAV。
- 单个背景音乐文件不得超过 30 MB。
- 素材名称可选，未填写时使用文件名。
- 系统读取并保存音频真实时长。
- 背景音乐支持在线试听。
- 背景音乐不设置默认项。

### 7.5.6 素材删除

- 删除素材前必须二次确认。
- 删除素材后无法在产品内恢复。
- 被项目引用的片头或背景音乐删除后，系统解除对应项目的素材关联。
- 如果删除默认片头，系统将剩余片头中 ID 最大的一项设为默认。

## 7.6 剪映草稿

### 7.6.1 生成前置条件

- 项目必须存在。
- 项目必须包含分镜。
- s2–s6 必须全部具有当前图片。
- s0–s6 必须全部具有旁白音频。
- 项目必须关联片头。
- s0、s1 的旁白必须能够完整落在片头分配时长内。

### 7.6.2 草稿画布

- 默认画布为 1080 × 1920 竖屏。
- 用户可通过剪映草稿提示词调整可解析的分辨率和文字样式参数。

### 7.6.3 视频与图片时间线

- 片头从时间线 0 秒开始。
- 片头保留原声，音量为 60%。
- s0、s1 使用片头画面，不添加图片。
- s2 从片头结束位置开始。
- s2–s6 的图片时长以对应旁白真实音频时长为准。
- 图片按原始宽高比计算铺满竖屏所需缩放比例。

### 7.6.4 图片动画

- 系统为 s2–s6 的图片随机分配关键帧动画。
- 动画组合包含推进、拉远、水平移动、垂直移动、对角移动及轻微旋转。
- 每次生成草稿时重新随机排列动画组合。

### 7.6.5 标题与作者

- 书名标题格式为《书名》。
- 书名从 s2 第一帧开始显示并持续到视频结束。
- 作者信息从 s2 第一帧开始显示并持续到视频结束。
- 作者为空时使用“作者待核实”。
- 作者文本过长时自动缩小字号，并优先在接近中间位置的标点处换行。

### 7.6.6 字幕

- 系统按中文和英文标点拆分每段口播字幕。
- 每个字幕片段的显示时长按去除空格后的文字长度比例分配。
- s0、s1 字幕落在片头对应时间范围内。
- s2–s6 字幕落在对应旁白真实时间范围内。

### 7.6.7 旁白与背景音乐

- 每条旁白从对应分镜起点开始添加，音量为 100%。
- 背景音乐为可选项。
- 选择背景音乐后，系统将音乐循环铺满整条视频。
- 最后一段背景音乐按视频剩余时长截断。
- 背景音乐音量固定为 12%。

### 7.6.8 草稿提示词

- 系统提供默认剪映草稿提示词。
- 用户可以修改提示词。
- 系统从提示词中解析画布分辨率、书名样式、作者样式和字幕样式。
- 无法解析的参数使用系统默认值。
- 每个草稿版本保存生成时使用的提示词。

### 7.6.9 草稿版本

- 每次成功生成草稿后新增一个版本。
- 版本按创建顺序倒序展示。
- 用户可复制任一版本的草稿链接。
- 用户可将历史版本设为当前版本。
- 切换版本时同步恢复该版本的草稿提示词。
- 用户可移除草稿版本记录。
- 移除版本记录不会删除剪映服务中的原始草稿。
- 如果移除的是当前版本，系统自动选择剩余的最新版本作为当前版本；无剩余版本时清空当前草稿。

## 7.7 批量生成

### 7.7.1 批量参数

- 每次生成数量最少为 1，最多为 20。
- 必须选择片头。
- 片头真实时长必须不小于 2.3 秒。
- 背景音乐可选。
- 同一批次所有项目使用相同片头和背景音乐。

### 7.7.2 去重规则

- 已有项目的书名全部进入不可选清单。
- 本批次已经生成成功的书名立即进入不可选清单。
- 模型不得使用相同书籍的简称、全称、别名、带或不带书名号、带或不带副标题、不同标点形式规避去重。

### 7.7.3 执行与进度

- 页面展示批次总进度、已完成数量、当前任务和任务队列。
- 当前任务展示六个执行步骤及其等待、执行中、已完成或失败状态。
- 图片生成阶段展示当前生成的分镜编号和图片进度。
- 配音生成阶段展示当前生成的分镜编号和配音进度。
- 批量任务执行期间不可关闭批量窗口。
- 所有项目完成后展示完成数量。

### 7.7.4 失败处理

- 任一步骤失败时，将当前书籍标记为失败。
- 系统保留失败前已经创建的项目和已经生成的素材。
- 当前实现不自动重试失败步骤。
- 当前实现不继续执行队列中后续书籍。
- 用户可关闭结果窗口或重新设置批量任务。

## 7.8 模型配置

### 7.8.1 能力类型

系统分别维护以下五类模型配置：

| 能力 | 用途 |
| --- | --- |
| 文生图 | 生成 s2–s6 分镜图片 |
| 图生图 | 编辑已有分镜图片 |
| 多模态 | 选书、整理书籍信息并生成脚本 |
| 视频 | 使用 Seedance 生成片头 |
| 语音合成 | 生成分镜旁白 |

### 7.8.2 配置字段

- 服务商类型：自定义兼容接口或 MiniMax。
- Base URL。
- 模型名称。
- API Key。
- 语音能力额外包含发音人 ID。

### 7.8.3 保存规则

- 每项能力独立保存配置。
- Base URL 保存时移除末尾斜杠。
- 页面只显示 API Key 是否已经配置，不回显已保存的 Key。
- 用户未填写新 API Key 时，保存其他字段不得清空原 Key。
- 未保存配置时，可回退使用环境变量中的对应配置。

### 7.8.4 连接测试

- 语音模型通过实际合成一段测试语音验证连接。
- 其他能力优先请求模型列表接口验证连接和模型名称。
- 服务未提供模型列表但接口地址可访问时，返回“地址可访问、未校验模型名称”。
- 普通连接测试超时时间为 15 秒。
- 语音连接测试请求超时时间为 30 秒。

## 8. 页面状态与步骤控制

- 无分镜时，当前进度为第一步。
- 已生成脚本但图片未全部完成时，当前进度为第二步。
- s2–s6 图片全部完成但配音未全部完成时，当前进度为第三步。
- 七条配音全部完成后，当前进度进入第四步。
- 已生成草稿时，第四步保持完成状态。
- 用户可以点击步骤导航查看此前步骤。
- 尚未具备前置数据时，对应步骤显示引导用户先生成脚本的空状态。

## 10. 数据存储与外部依赖

### 10.1 本地存储

- 项目使用 SQLite 数据库保存。
- 数据库文件位于 `data/creatorflow.db`。
- 项目元数据、分镜、素材文件、模型配置和草稿版本均保存在本地数据库中。
- 当前产品不包含用户账号或不同用户的数据隔离。

### 10.2 外部服务

- 脚本生成依赖 OpenAI Chat Completions 兼容接口。
- 文生图依赖 MiniMax 图片接口或 OpenAI Images 兼容接口。
- 图生图依赖 OpenAI Images Edits 兼容接口。
- 视频生成依赖 Seedance 任务接口。
- 语音生成依赖 MiniMax `t2a_v2` 接口格式。
- 剪映草稿生成依赖 CapCut Mate 外部服务。
- 任一外部服务不可用时，对应生成能力不可完成。

## 11. 异常与提示要求

- 输入缺失时，页面或接口应明确提示缺失字段。
- 模型配置不完整时，应提示先配置对应模型、Base URL 和 API Key。
- 外部接口返回失败时，应展示能力名称和可用的错误信息。
- 项目不存在时，应返回“未找到该书籍解说”。
- 素材不存在或仍在生成时，应展示对应状态，不返回无效媒体。
- 生成中的按钮应显示执行中状态，并避免重复提交同一操作。
- 图片、配音、草稿和批量流程均应显示当前处理状态。
- 剪贴板写入失败时，应提示用户检查浏览器剪贴板权限。

## 13. 验收标准

### 13.1 单本完整链路

- 配置有效模型并准备时长不小于 2.3 秒的片头后，用户可以成功生成一个包含 7 个分镜的项目。
- s1 口播必须为“今天我们分享的是”。
- s2 口播必须为带书名号的当前书名。
- 用户可以成功生成 5 张图片和 7 条配音。
- 素材完整后可以成功生成剪映草稿链接。
- 再次生成草稿后，页面至少存在两个草稿版本。

### 13.2 图片编辑链路

- 用户可以修改任一 s2–s6 的图片提示词。
- 用户可以重新生成图片，并在版本列表中看到新版本。
- 用户可以切换到历史图片版本。
- 用户可以基于当前图片执行图生图编辑，并将结果作为当前版本。

### 13.3 素材链路

- 用户可以上传片头并正确读取时长。
- 第一个片头自动成为默认片头。
- 用户可以上传并试听背景音乐。
- 用户可以提交 Seedance 片头生成任务并手动刷新状态。
- 用户可以删除素材，相关项目引用被解除。

### 13.4 批量链路

- 用户可以设置 1–20 本的批量任务。
- 系统逐本生成完整脚本、5 张图片、7 条配音和剪映草稿。
- 同一批次及已有项目中不应出现标准书名完全相同的项目。
- 页面能够展示批次进度、当前步骤和每本任务状态。
- 任一环节失败后，当前任务显示失败原因并停止后续处理。

### 13.5 数据持久化

- 页面刷新后，项目、分镜图片、图片版本、音频、背景音乐选择和草稿版本仍可读取。
- 模型 API Key 保存后不在页面回显。
- 删除项目后，项目及其关联分镜和草稿版本不再可读取。
